## 必须完成的真实钱包检查

1. 在已有 EVM 钱包的 Edge 或 Chrome 打开签发工作台；内置浏览器没有钱包时无法代替这一步。
2. 使用专用测试账户并切到 Monad Testnet，链 ID 10143，余额包含测试 MON。钱包的解锁在录制前完成。
3. 保持一份默认研究笔记，点击“签发并登记凭证”，亲自完成连接、EIP-712 签名与测试交易确认。
4. 等到“已登记”，下载 JSON，并保留对应原文字节和交易哈希。在消费端导入后应全部通过；修改原文后应失败。
5. 把交易哈希或具体页面错误反馈到本聊天。程序的脚本钱包回归检查不能替代这项实际浏览器证据。

取消钱包交易或确认查询失败时，签名凭证仍可下载，状态不会显示已登记；已取得的交易哈希会留在页面。先下载备份，稍后独立验证，不要因等待重复登记。
