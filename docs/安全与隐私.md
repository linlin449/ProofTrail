# 安全与隐私边界

这是参赛原型，未完成第三方安全审计。核心信任是持有者配置的网络/合约与发行者密钥，不是平台自报的绿色状态。

- 签名不能证明内容真实、模型确实运行、发行者现实身份或版权。
- 公共链永久记录根与撤销信息；随机 salt 混入签名摘要后再建树，链上不直接存可枚举的原文哈希，但持有完整凭证的人可猜测低熵内容。
- 内容在链下不等于隐私：若在在线 API 输入内容，服务器能看到；应使用本地 SDK 计算与验证敏感数据。
- 演示仅用虚构内容，不上传真实用户资料；不记录内容正文到日志。
- 本地演示私钥只对应内存测试链预置账户，不要在真实网络使用这些密钥。
- 在线写操作需发行者自己的钱包签名；禁止公开服务器演示签名密钥或开放未鉴权签发/撤销 API。
- RPC 出错、链不匹配、合约无代码、schema 不合法、证明无效，均不得显示验证成功。
- 当前 v1 支持 EOA EIP-712 签名；不承诺 EIP-1271 智能合约钱包支持。
- 元数据 model/application 是发行者声明，不是经过模型厂商证明的事实。

后续审查覆盖：重放/域替换、未知网络、假锚点、发行者替换、错误 Merkle 路径、重复锚定、未授权撤销、过期、RPC 错误、超大请求与前端注入。
