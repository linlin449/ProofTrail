## Pitch：2 分钟以内

“我是 Bubble，单人项目叫 ProofTrail。AI 内容容易复制，但出处声明与撤销状态经常留在原来的平台。另一个应用接到内容后，往往只能继续相信平台的数据库。

ProofTrail 提供可移植凭证。Python 应用对输出字节和固定元数据签名，批量根登记到 Monad；另一个应用持有原文和 JSON 包，即可检查发行者、内容变化和撤销状态。

我们先服务研究工具和知识发布应用。开发者需要清楚的接口和可复现路径。当前实现了独立 SDK、批量证明、发行者撤销与分项验证；部署和材料状态会按真实结果更新。

下一步是与一位真实开发者接入，测量接入时间和跨应用携带体验。来源凭证不证明事实、现实身份或版权。明确这个边界，让可组合的内容基础设施从一个可检查的工具开始。”
