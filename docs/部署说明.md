# Monad 测试网与产品部署

## 当前事实

2026-10-03 已确认 Monad 测试网合约 `0xd4c01FEdb19eF081AAF3c6814316d8CeF7579Cd7`，链 10143。部署交易与 runtime 比对记录在 `artifacts/monad-deployment.json`；Sourcify creation/runtime 精确匹配记录在 `artifacts/verification/sourcify-record.json`。公开源码仓库为 [linlin449/ProofTrail](https://github.com/linlin449/ProofTrail)，外网 Python 服务已上线并验收：[签发端](https://prooftrail-issuer.vercel.app) 与 [独立消费端](https://prooftrail-consumer.vercel.app)，详情见 [在线发布](在线发布.md)。默认不带 `--mode monad` 的演示仍使用本地 EVM。

完整地址、真实交易、测量与本机检查命令见 [Monad 实测与检查](Monad实测与检查.md)。不需要再次广播部署。

## 测试网预检

```powershell
uv run python scripts/deploy_testnet.py
```

从官方 [网络信息](https://docs.monad.xyz/developer-essentials/testnet) 核对 RPC 与链 ID。脚本限定 chainId=10143，拒绝其他网络。预检不会发送交易。

## 部署

为专用测试账户从官方 [水龙头](https://faucet.monad.xyz/) 领取测试 MON。通过本机环境变量配置 `PROOFTRAIL_PRIVATE_KEY`，不要发到聊天。环境文件不会自动读取；避免误认为复制 .env 就生效。

```powershell
npm ci
npm run compile
uv run python scripts/deploy_testnet.py --broadcast
```

检查真实交易、部署地址、源码 SHA-256、编译器、runtimeMatches。编译目标 Paris 以避免依赖不必要的新操作码；没有管理员、升级器或资金转账函数。

部署脚本的 runtimeMatches 是本机比对；另已使用 `uv run python scripts/verify_source.py --publish` 通过 Sourcify API v2 发布 MIT 合约源码并取得 `exact_match`。再次运行不带参数只检查已保存的 ticket，不重新发布。可在 [Sourcify](https://repo.sourcify.dev/10143/0xd4c01FEdb19eF081AAF3c6814316d8CeF7579Cd7) 查阅。Sourcify 返回的 Etherscan 转发 ticket 不是 Monadscan 已成功的独立声明。

## 在线服务

配置 `PROOFTRAIL_RPC_URL`、`PROOFTRAIL_CONTRACT`、`PROOFTRAIL_ALLOWED_HOSTS`，使用 HTTPS 托管；不将测试签名私钥配置进服务。运行：

```powershell
uv run python -m prooftrail serve --mode monad --host 0.0.0.0 --port 8765
```

在线写操作仅由用户钱包发起；服务器演示写接口在 monad 模式返回 403。部署前需要核对托管平台、公开内容与域名。最终比赛提交仍等用户确认。

## 部署后验收

- /health 连接可信链与正确 runtime bytecode。
- 浏览器连接测试账户签名与登记，独立 SDK 验证同一凭证。
- 另一账户无法撤销发行者凭证；发行者撤销后独立消费者读到新状态。
- 保存真实登记交易与 Gas、确认耗时，和本地 benchmark 分开。
- 外网加载 JS/CSS 正确，敏感密钥不在静态文件、日志、仓库或容器镜像中。
