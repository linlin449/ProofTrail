## 当前方案：Vercel Hobby + FastAPI

用户已有登录的 Hobby 账号。新建两个项目，均导入公开 ProofTrail 仓库，根目录保持 ./，Application Preset 选择 FastAPI。签发项目使用默认 PROOFTRAIL_APP=issuer；独立消费项目设置 PROOFTRAIL_APP=consumer。无需钱包私钥、付费数据库或 AI API 密钥。只部署这个个人测试网项目，未升级付费套餐。

`main.py` 导出 FastAPI 实例，`vercel.json` 指定 60 秒请求时限和运行资源，`.vercelignore` 仅允许公开源码与依赖锁文件。`serverless.py` 在构建导入时不访问 RPC，实际请求才创建经过链 ID/字节码检查的 Registry；连接失败不会缓存为成功，也不会退回本地演示链。验证时仍重新读取链上撤销状态。签发端的凭证列表仅为当前进程内存，重启或多实例不保证保存，下载的凭证和 Monad 登记才是跨实例证据。

Host 默认仅允许本服务的 VERCEL_URL、VERCEL_BRANCH_URL、VERCEL_PROJECT_PRODUCTION_URL 与原有回环地址；显式允许列表优先。没有允许整个 vercel.app 域名。

依据：[FastAPI 部署](https://vercel.com/docs/frameworks/backend/fastapi)、[Python 运行时](https://vercel.com/docs/functions/runtimes/python)、[Hobby 方案](https://vercel.com/docs/plans/hobby)、[运行时域名变量](https://vercel.com/docs/environment-variables/system-environment-variables)。本地入口记录 `vercel-entrypoint-probe.json` 与匿名公网记录 `public-hosting-probe.json` 分开保留。云端使用官方 PyPI，依赖版本保持原锁定值；现有用户环境若设有 UV_DEFAULT_INDEX，可在本次终端指定 `https://pypi.org/simple` 后用 `uv sync --locked --extra dev` 复现。

Vercel 采用按请求运行的 Python 函数，存在冷启动、请求时限和免费额度限制，不承诺常驻或无限使用。当前 Git 连接会自动构建 main 上的新提交；仅选择 Hobby，未开付费数据库、Analytics 或升级套餐。
