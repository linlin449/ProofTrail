# 跨语言一致性检查

`artifacts/protocol-vector.json` 是固定的公开测试向量，域为测试链 10143 与虚构地址 0x111…111，不是部署地址。生成器使用公开测试私钥整数 1，绝不供部署脚本使用。

```powershell
uv run python scripts/generate_vector.py
npm run test:vectors
```

Python 使用 eth-account 产生签名与 Merkle 包；独立 JS 使用 ethers 复算 EIP-712 digest、恢复发行者、重算原文 SHA-256、规范化元数据、Merkle 路径与 ABI batch ID。

这个检查比同一个 Python 实现自己签名自己恢复更强，但不等于第三方安全审计。JSON 元数据规范限定字符串，避免不同语言对浮点/大整数的序列化歧义。
